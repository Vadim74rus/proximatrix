# Настройка WhatsApp через прокси Proximatrix

Прокси для WhatsApp работает по **HTTP** и **HTTPS**. Используйте адрес сервера и порты ниже.

**Данные прокси:**
- **Сервер (IP):** `77.221.156.12`
- **HTTP-прокси:** порт `8080`
- **HTTPS-прокси:** порт `8443`

---

## WhatsApp Web (в браузере на компьютере)

WhatsApp Web не умеет настраивать прокси сам — прокси настраивается **в браузере**. После этого все сайты, включая web.whatsapp.com, пойдут через прокси.

### Chrome или Edge

1. Установите расширение **Proxy SwitchyOmega**:
   - Chrome: [Chrome Web Store — Proxy SwitchyOmega](https://chrome.google.com/webstore/detail/proxy-switchyomega/padekgcemlokbadohgkifijomclgjgif)
   - Edge: найдите «Proxy SwitchyOmega» в Edge Add-ons

2. Откройте настройки расширения (иконка в панели расширений → **Options**).

3. Нажмите **«Новый профиль»** (или **Create new profile**):
   - **Название профиля:** `Proximatrix` (или любое)
   - **Тип:** «Proxy Profiles» → **HTTP/HTTPS**

4. Заполните:
   - **Protocol:** `HTTP`
   - **Proxy Server:** `77.221.156.12`
   - **Proxy Port:** `8080`

5. Включите **«Same proxy for HTTPS»** (тот же прокси для HTTPS) и укажите:
   - **Proxy Server:** `77.221.156.12`
   - **Proxy Port:** `8443`  
   (или оставьте те же 8080, если в расширении один адрес для HTTP и HTTPS — тогда оба порта можно проверить по очереди).

6. Нажмите **«Применить»** (Apply).

7. В панели расширения выберите профиль **Proximatrix** (включите его).

8. Откройте [https://web.whatsapp.com](https://web.whatsapp.com) и войдите в аккаунт — трафик пойдёт через прокси.

Чтобы отключить прокси: в Proxy SwitchyOmega выберите **«Direct»** (напрямую).

---

### Firefox

1. Откройте **Настройки** (меню ≡ → **Settings**).

2. В поиске настроек введите **proxy** или прокрутите до раздела **Сеть** (Network).

3. Нажмите **«Настройки…»** (Settings…) в блоке «Настройки подключения».

4. Выберите **«Ручная настройка прокси»** (Manual proxy configuration).

5. Заполните:
   - **HTTP-прокси:** `77.221.156.12`
   - **Порт:** `8080`
   - Включите **«Использовать этот прокси-сервер для всех протоколов»**  
     **или** отдельно укажите для HTTPS:
   - **SSL-прокси (HTTPS):** `77.221.156.12`
   - **Порт:** `8443`

6. Нажмите **OK**.

7. Откройте [https://web.whatsapp.com](https://web.whatsapp.com) и войдите — трафик пойдёт через прокси.

Чтобы отключить: в тех же настройках выберите **«Без прокси»**.

## WhatsApp на телефоне (Android / iPhone)

В самих настройках WhatsApp **нет** пункта «прокси». Поэтому варианты такие:

### Вариант 1: Прокси только для браузера (телефон без прокси)

- На телефоне используйте обычный WhatsApp **без** прокси.
- Через прокси работает только **WhatsApp Web** в браузере на компьютере (как в шагах выше).

### Вариант 2: Системный прокси или Wi‑Fi прокси (Android)

На части Android-устройств можно задать HTTP-прокси для Wi‑Fi:

1. **Настройки** → **Сеть и интернет** → **Интернет** (или **Wi‑Fi**).
2. Нажмите на вашу сеть Wi‑Fi (долгое нажатие) → **Изменить** / **Дополнительно**.
3. В разделе «Прокси» выберите **«Вручную»** (Manual).
4. **Имя узла прокси:** `77.221.156.12`  
   **Порт прокси:** `8080`
5. Сохраните. Весь трафик по этому Wi‑Fi (включая WhatsApp) пойдёт через прокси.

Минус: прокси будет только когда телефон в этой Wi‑Fi сети.

### Вариант 3: Приложение-прокси (Android)

Установите приложение, которое поднимает локальный HTTP-прокси и перенаправляет трафик на ваш сервер, например:

- **ProxyDroid** (нужен root), или
- приложения вроде **HTTP Proxy** / **Proxy Server**, которые умеют задавать upstream HTTP-прокси.

В настройках такого приложения укажите:
- **Сервер:** `77.221.156.12`
- **Порт:** `8080`

Дальше настройте в приложении, какой трафик (или какое приложение) идёт через этот прокси.

### Вариант 4: VPN через ваш сервер

Если развернуть на том же сервере VPN (WireGuard, OpenVPN и т.п.) и подключиться с телефона к этому VPN, то весь трафик телефона, включая WhatsApp, пойдёт через сервер. Это уже не настройка «прокси в WhatsApp», а общая настройка VPN на устройстве.

## Проверка работы прокси

**На сервере (в PuTTY):**
```bash
curl --proxy http://77.221.156.12:8080 http://ifconfig.me
```
В ответе должен быть IP `77.221.156.12`.

**На вашем ПК в браузере:**  
После включения прокси откройте, например, [https://ifconfig.me](https://ifconfig.me) — должен отображаться IP вашего сервера `77.221.156.12`.
