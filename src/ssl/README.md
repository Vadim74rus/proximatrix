# SSL-сертификаты для API (aiquantums.ru)

В этой папке лежат сертификаты для HTTPS API:

- **certificate.crt** — сертификат сервера
- **certificate.key** — закрытый ключ
- **certificate_ca.crt** — цепочка CA (если нужна для клиентов)
- **certificate.csr** — запрос на сертификат (для сервера не используется)

Использование: API управления пользователями (порт 9090) поднимается по **HTTPS**, если в конфиге заданы `api.sslCert` и `api.sslKey` (или переменные окружения `SSL_CERT_PATH`, `SSL_KEY_PATH`). Тогда обращение к API — по адресу **https://aiquantums.ru:9090** (или по IP).

**Важно:** Подключение **Telegram к MTProxy (порт 8444)** не использует TLS — протокол MTProto уже шифрован. Сертификаты нужны только для защиты доступа к **API** (управление пользователями, получение ссылок и т.д.).
