# ✅ Реализован контроль доступа по IP

Система отслеживания IP и автоматического отключения при подозрительной активности успешно реализована!

---

## 🎯 Что реализовано

### 1. Отслеживание IP-адресов
- Автоматическое отслеживание IP каждого подключения
- Хранение истории подключений в MongoDB
- Запоминание первого IP как разрешенного

### 2. Автоматическое отключение
- При обнаружении одновременных подключений с разных IP → автоматическое отключение (`enabled: false`)
- Пользователь не удаляется, только отключается
- Возможность восстановления доступа через API

### 3. Уведомления администратору
- Подробные уведомления в логах при обнаружении подозрительной активности
- **Автоматическая отправка уведомлений в Telegram** через внешний API (если настроено)
- Информация о пользователе, IP-адресах и причине блокировки

### 4. API для управления
- `GET /api/users/{id}/connections` — просмотр истории подключений
- `POST /api/users/{id}/reset-ips` — сброс разрешенных IP

## 🚀 Как использовать

### После деплоя система работает автоматически:

1. **Первое подключение** — IP автоматически добавляется в разрешенные
2. **Одновременное подключение с другого IP** → автоматическое отключение
3. **Уведомление в логах** с подробной информацией
4. **Восстановление через API** после проверки

### Примеры команд:

```bash
# Просмотр истории подключений
curl -H "X-API-Key: proximatrix-api-key-change-in-production" \
  http://77.221.156.12:9090/api/users/{id}/connections

# Включить пользователя обратно
curl -X POST -H "X-API-Key: proximatrix-api-key-change-in-production" \
  http://77.221.156.12:9090/api/users/{id}/enable

# Сбросить разрешенные IP
curl -X POST -H "X-API-Key: proximatrix-api-key-change-in-production" \
  http://77.221.156.12:9090/api/users/{id}/reset-ips
```

## 🔔 Настройка уведомлений (опционально)

Для получения уведомлений в Telegram при обнаружении подозрительной активности:

1. Добавьте в `docker-compose.yml`:
   ```yaml
   environment:
     NOTIFY_API_URL: "https://blacknetiv.ru"
     NOTIFY_SECRET: "ваш-секретный-ключ"
   ```

2. Перезапустите контейнер:
   ```bash
   docker compose restart proximatrix
   ```

Подробнее: **`NOTIFY_SETUP.md`**
