# Домен и сайт на сервере Proximatrix

Ссылки на прокси по умолчанию генерируются с **IP** (77.221.156.12). Чтобы использовать домен, укажите его в `publicIp` / `PROXY_PUBLIC_IP` и настройте A-запись в DNS.

---

Пример настройки DNS у Рег.ру (если используете домен):
- **A запись** `@` → `77.221.156.12` (главная страница домена)
- **A запись** `www` → `77.221.156.12`
- DNS-серверы: ns1.reg.ru, ns2.reg.ru

При переходе на сайт в браузере пишет **«сервер недоступен»**, потому что на сервере **нет веб-сервера** на портах 80 (HTTP) и 443 (HTTPS). Proximatrix слушает только порты прокси и API (8444, 8080, 8443, 9090 и т.д.).

Ниже — что делать в зависимости от цели.

---

## Вариант 1: Домен нужен только для ссылки на прокси

Если домен нужен только для красивой ссылки на MTProxy (например, `https://t.me/proxy?server=ваш-домен.ru&port=8444&secret=...`):

1. **Ничего дополнительно настраивать не нужно** — A-записи уже указывают на `77.221.156.12`.
2. В настройках Proximatrix укажите домен вместо IP (если где-то прописан адрес):
   - в **config.json**: `"publicIp": "ваш-домен.ru"` (или оставьте IP — оба варианта работают);
   - в **@MTProxyBot** при регистрации можно указать ссылку с доменом:  
     `https://t.me/proxy?server=ваш-домен.ru&port=8444&secret=ВАШ_СЕКРЕТ`
3. Откройте порт **8444** в файрволе (если ещё не открыт):
   ```bash
   ufw allow 80/tcp
   ufw allow 443/tcp
   ufw allow 8444/tcp
   ufw reload
   ```
   (80/443 пригодятся, если позже поставите сайт.)

Открывать в браузере `http://ваш-домен.ru` при этом не обязательно — для прокси важен только домен в ссылке Telegram.

---

## Вариант 2: Нужен настоящий сайт (страница открывается в браузере)

Чтобы при переходе на `http://ваш-домен.ru` или `https://ваш-домен.ru` что-то открывалось, на сервере должен работать **веб-сервер** на портах 80 и 443.

### Шаг 1: Подключитесь к серверу по SSH

```bash
ssh root@77.221.156.12
```

### Шаг 2: Установите nginx

```bash
apt update
apt install -y nginx
```

### Шаг 3: Откройте порты 80 и 443 в файрволе

```bash
ufw allow 80/tcp comment 'HTTP сайт'
ufw allow 443/tcp comment 'HTTPS сайт'
ufw reload
ufw status
```

### Шаг 4: Простая главная страница

Создайте страницу по умолчанию:

```bash
nano /var/www/html/index.html
```

Вставьте (подставьте свой текст и ссылку на канал):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Proximatrix Proxy</title>
</head>
<body style="font-family: sans-serif; max-width: 600px; margin: 2rem auto; padding: 1rem;">
  <h1>Proximatrix</h1>
  <p>MTProxy для Telegram и прокси для WhatsApp.</p>
  <p>Подключение по ссылке из Telegram или через настройки прокси в приложении.</p>
  <p><a href="https://t.me/ai_quantums">Наш канал</a></p>
</body>
</html>
```

Сохраните: `Ctrl+O`, Enter, `Ctrl+X`.

### Шаг 5: Проверка

- На сервере: `curl -I http://localhost` — должен вернуть ответ от nginx (200 OK).
- С компьютера откройте в браузере: `http://ваш-домен.ru`  
  (замените на ваш домен). Должна открыться созданная страница.

Если домен только что настроен, подождите 5–15 минут после сохранения записей в Рег.ру.

---

## Вариант 3: Редирект с сайта на канал Telegram

Вместо страницы можно сделать перенаправление на канал:

```bash
nano /etc/nginx/sites-available/default
```

В блоке `server { ... }` найдите `location /` и замените на:

```nginx
location / {
    return 302 https://t.me/ai_quantums;
}
```

Потом:

```bash
nginx -t
systemctl reload nginx
```

Тогда при открытии `http://ваш-домен.ru` браузер перейдёт в канал.

## Кратко

| Цель | Действие |
|------|----------|
| Только ссылка на прокси с доменом | A-записи уже есть; используйте домен в ссылке `t.me/proxy?server=ваш-домен.ru&port=8444&secret=...`. Сайт в браузере не обязателен. |
| Открывать сайт в браузере | Установить nginx, открыть 80/443, создать страницу в `/var/www/html/index.html` или редирект (см. выше). |

После настройки DNS в Рег.ру подождите несколько минут; при первом запуске nginx проверьте `ufw status` и доступ по `http://ваш-домен.ru`.
